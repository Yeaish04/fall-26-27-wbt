    ## 2 types of link in HTML :
    (1) Relative Lik : Link a file from same folder or different folder of the code. [Link from inside the PC]
    (2) Absolute Link [Any link from any website or anywhere outside the PC]

    ## 2 type of tags in html:
    (1) Semantic Tag     --> The tag clearly tells what the content means/purpose is.
    (2) Non-Semantic Tag --> The tag doesn't tell you what the content means; it mainly acts as a container.


    ## <div></div>(Division TAG)
--> Used to group larger/block sections of a webpage.
--> Block Element [use the full length of the line]
    ## <span></span>(SPAN TAG) 
--> Used to group or style a small piece of text/content, usually inside a line.
--> Inline Element [Use the only length which is covered by the characters/codes]

    ## Anchor TAG --> add website link in the website.[Can be Reltaive Link or Absolute Link]
    ## IFrame TAG --> add functional website inside a website. For example : video playing from youtube inside a website make by me .
    ## Video TAG  
    --> add VIDEOS in the website.[Can be Reltaive Link or Absolute Link]

    ## 3 Type of TAGS under <main></main> TAG :
    (1) Section TAG : <section></section> --> Used to divide a webpage into logical sections.
    (2) Article TAG : <article></article> --> Used for content that could be independent by itself. Example : Blog post, News article
    (3) Aside TAG   : <aside></aside>     --> Used for content that is related to the main content but not essential. Exmaple : Advertisements
